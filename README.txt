AKOLADE KAOSARA ABIMBOLA — MULTI-PAGE STUDENT PORTFOLIO

OPENING THE WEBSITE
1. Extract this ZIP archive.
2. Open index.html in a modern browser. It will take you to home.html.
3. Keep all HTML files, styles.css and script.js together in the same folder.

PAGE ORDER
1. index.html — entry point
2. home.html — Home
3. about.html — About Me
4. skills.html — Skills
5. projects.html — Projects
6. planner.html — Academic Planner
7. contact.html — Contact

FILES
- Each requested section has its own HTML file.
- styles.css contains the shared visual design.
- script.js contains the mobile navigation, academic planner and contact form behavior.
- There are no screenshots, photographs, or image assets in this version.

CONTENT
The write-up has been consolidated from the supplied portfolio material. Repeated biography and project descriptions have been removed. The original academic details, skills, and three project topics are retained.

FUNCTIONAL NOTES
- Academic planner tasks are stored in browser local storage on the device where they are entered.
- The contact form prepares a message in the visitor's default email app. A recipient address was not supplied in the source material, so no email address has been invented.
- Google Fonts are loaded online; system fallback fonts are included.
